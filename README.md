CSC 172 Lab 3
This lab has us analyze sorting algorithms by running each of them (built-in Java Arrays,sort() function, bubble sort, selection sort, insertion sort, merge sort, and quicksort) on different array. One array is random, one is sorted, one is reversed, and one is nearly sorted. This allows us to see which sorting algorithms work best and where they work best. Some algorithms might perform poorly on a random array, but very well on a nearly sorted array, for example. Graphs of the sorting algorithm efficiency for each size for each array are included in screenshots of the output.
